扬声器除水完整版

用低频声波把喇叭里的积水和灰尘震出来

开始前请确认：① 手机静音开关关掉（iPhone 侧边拨杆）② 音量调到最大 ③ 让扬声器朝下
连续

添加到主屏幕，下次一点就用

  1. 如果是在小红书或微信里打开的：点右上角 「…」→ 在浏览器打开
  2. 在 Safari 里点底部的分享按钮（方框加向上箭头）
  3. 往下找到「添加到主屏幕」

添加后主屏幕上会多一个「除水」图标，打开过一次以后，没网也能用。安卓手机在 Chrome 菜单里选「添加到主屏幕」。

怎么选模式

  1. 刚进水、声音发闷：先用「扬声器除水」，选 3 轮
  2. 还有一点闷：换「脉冲除水」。声音一下一下地推，比一直响更容易把卡住的水珠震松
  3. 声音沙沙的、有杂音：用「深度清洁」，扫过更多频率，对付顽固水珠和灰尘
  4. 想确认好了没有：用「声道检测」，左边、右边会轮流响，两边都清楚就说明好了

正确用法

  1. 进水后尽快做，水停留越久越难震出来
  2. 扬声器朝下拿着，可以轻轻甩动手机
  3. 多轮之间会休息 3 秒，让震出来的水往下流
  4. 震出来的水用纸巾吸掉，别用吹风机热风吹
  5. 进的是海水、饮料等液体，声波解决不了残留和腐蚀，请尽快送修
  6. 如果只有通话听筒（屏幕上方）不响、外放正常，大概率不是进水
